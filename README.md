## 🛠️ Featured Projects

> These are the projects I'd point a reviewer to first. Descriptions below are written from what each repo demonstrates — swap in your own repo `description` field and topics so they render identically on the pinned cards.

### 🕵️ Multi-Stage Cyber-Fraud Early-Warning & Forensic Intelligence Platform
**[Repo](https://github.com/sathi2305/Multi-Stage-Cyber-Fraud-Early-Warning-Forensic-Intelligence-Platform)** · **[Live Demo →](https://multi-stage-cyber-fraud-early-warning.onrender.com)**

Correlates messages, conversation trajectories, shared URLs, and uploaded digital evidence to detect **escalating multi-stage social-engineering scams** — classifying a conversation's position in the scam lifecycle (contact → rapport → credibility → urgency → extraction) so intervention can happen *before* a victim sends money, not after.

`Python` `Flask` `NLP` `Threat Intelligence`

### 🧠 AI-Based IoT Security Anomaly & Attack Detection
A machine learning pipeline for detecting security threats in IoT environments. Trained a **Random Forest classifier** on synthetic sensor data to separate normal device behaviour from attack traffic, with accuracy evaluation and a visualized confusion matrix.

`Python` `scikit-learn` `Random Forest` `IoT Security`

### 💊 PolyPharm-Twin — Real-Time Multi-Drug Metabolic Simulator
A clinical decision-support system that models multi-drug metabolic interactions for polypharmacy patients (5+ concurrent medications). Represents human drug metabolism as a **dynamic knowledge graph**, simulating real-time competition for shared liver CYP450 clearance pathways to flag dangerous interaction risk.

`Python` `Knowledge Graphs` `Clinical Decision Support`

### 🐾 Smart Pet Feeder System
A closed-loop IoT device that dispenses food on schedule, tracks hopper inventory via ultrasonic sensing, confirms portion accuracy with a load cell, and syncs every feeding cycle live to a mobile app over Wi-Fi.

| Layer | Component | Role |
|---|---|---|
| Control | Arduino / ESP32 | Orchestrates schedule and real-time logic |
| Actuation | Servo motor | Dispenses precise portions |
| Sensing | Ultrasonic sensor | Monitors hopper level |
| Feedback | Load cell | Confirms portion weight |
| Connectivity | Wi-Fi module | Streams data, receives commands |

`Arduino` `ESP32` `Sensor Fusion` `IoT`
