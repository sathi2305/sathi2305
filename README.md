## 🛠️ Featured Showcase — Smart Pet Feeder Technology

> **An automated, closed-loop IoT device that dispenses food, tracks inventory, and confirms feeding cycles — all synced live to a mobile app.**

**🔩 Architecture Breakdown**

| Layer | Component | Function |
|---|---|---|
| 🧠 **Controller** | Arduino / ESP32 | Central brain — runs feeding schedules & logic |
| ⚙️ **Actuation** | Servo Motor | Dispenses precise food portions on command |
| 📏 **Sensing** | Ultrasonic Sensor | Monitors hopper food level, triggers low-supply alerts |
| ⚖️ **Feedback Loop** | Load Cell | Measures real-time bowl weight to stop dispensing at the target portion |
| 📶 **Connectivity** | Wi-Fi Module | Streams data to & receives commands from the mobile app |
| 📱 **Interface** | Mobile App | Lets the owner schedule feeds & confirm successful cycles remotely |

**⚡ Engineering Highlights**
- Designed a **closed-loop control system** — the microcontroller reacts to live sensor data instead of running on a blind timer
- Combined **two independent sensing modalities** (ultrasonic + load cell) for both inventory-level and portion-precision accuracy
- Built for **remote observability** — every feeding cycle is confirmed back to the owner over Wi-Fi, not just executed blind
- Full **hardware-to-software pipeline**: sensor input → microcontroller logic → actuator output → cloud/app sync
