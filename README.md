## 🛠️ Featured Project — Smart Pet Feeder System

> **An automated, closed-loop IoT device that dispenses food, tracks inventory, and confirms feeding cycles—all synced live to a mobile app.**

### 🔩 Architecture Breakdown

| Layer | Component | Responsibility |
|---|---|---|
| 🧠 **Control** | Arduino / ESP32 | Orchestrates feeding schedules and real-time logic |
| ⚙️ **Actuation** | Servo Motor | Dispenses precise food portions on command |
| 📏 **Sensing** | Ultrasonic Sensor | Monitors hopper food level, triggers low-supply alerts |
| ⚖️ **Feedback** | Load Cell | Measures real-time bowl weight for portion accuracy |
| 📶 **Connectivity** | Wi-Fi Module | Streams live data & receives commands from mobile app |
| 📱 **Interface** | Mobile App | Remote scheduling, monitoring, and feeding confirmation |

### ⚡ Engineering Highlights

✅ **Closed-Loop Control System** — Microcontroller reacts to live sensor data instead of running blind timers  
✅ **Dual Sensing Modality** — Ultrasonic + load cell combined for inventory-level and portion-precision accuracy  
✅ **Remote Observability** — Every feeding cycle confirmed back to owner over Wi-Fi  
✅ **Full Hardware-to-Software Pipeline** — Seamless data flow: sensor input → microcontroller logic → actuator output → cloud/app sync
